## Prerequisites

- OS: Linux
- Python: 3.10, 3.11, 3.12, 3.13

## Python Package (WIP)

FlashInfer-Bench is available via pip:

```bash
python3 -m pip install flashinfer-bench
```

## Install from Source

You may want to install FlashInfer-Bench from source code for development purposes.

```bash
# Clone the FlashInfer-Bench repository
git clone https://github.com/flashinfer-ai/flashinfer-bench.git

# Install the Python package
pip install -v -e .
```

## AMD ROCm / CDNA GPUs

On AMD Instinct GPUs (CDNA3 gfx942 — MI300X/MI325X; CDNA4 gfx950 additive), the GPU dependencies
come from AMD's package indexes rather than PyPI.

> ROCm support (the `docker/rocm/` container and the `[rocm]` extra) lives in the ROCm fork,
> `AMD-Ecosystem/flashinfer-bench`, not in upstream `flashinfer-ai/flashinfer-bench`.
>
> **The `flashinfer-bench` package on PyPI is the upstream NVIDIA build.** It carries no ROCm
> support and no `[rocm]` extra, so the "Python Package" and "Install from Source" sections above
> are the wrong path on AMD — follow this section instead.

```bash
# Clone the ROCm fork — not the upstream URL used in "Install from Source" above
git clone https://github.com/AMD-Ecosystem/flashinfer-bench.git
cd flashinfer-bench
```

The supported, reproducible path is the ROCm dev container:

```bash
# Build and enter the ROCm dev image (ROCm 7.2 + torch-ROCm + amd-flashinfer + amd_aiter + tvm-ffi)
bash docker/rocm/run.sh
# Validate the stack end-to-end on the GPU
bash docker/rocm/run.sh python3 docker/rocm/validate_p0.py
```

See `docker/rocm/README.md` for details. To install into an existing ROCm environment instead:

```bash
# 1) ROCm build of torch (match your ROCm version). The Radeon URL is a find-links page
#    (not a PEP 503 index), so use -f to keep PyPI available for torch's pure-python deps.
#    Pin the version: unpinned, pip can prefer a newer CPU-only torch from PyPI over the ROCm
#    wheel and silently break the install. 2.9.1 / ROCm 7.2 is what docker/rocm/Dockerfile pins.
python3 -m pip install "torch==2.9.1" -f https://repo.radeon.com/rocm/manylinux/rocm-rel-7.2/
# 2) flashinfer-bench + ROCm extras, installed from the fork clone above. Install from source, not
#    by name: the `[rocm]` extra exists only in this fork, so `pip install "flashinfer-bench[rocm]"`
#    would resolve upstream's NVIDIA package off PyPI and silently drop the extra.
#    The two AMD wheels live under different, ROCm-version-specific index paths (mirroring
#    docker/rocm/Dockerfile) — don't mix versions:
#      amd-flashinfer (imports as `flashinfer`) -> rocm-7.2.0 index
#      amd_aiter (AITER-backed solutions)       -> rocm-7.1.1 index
python3 -m pip install -e ".[rocm]" \
    --extra-index-url https://pypi.amd.com/rocm-7.2.0/simple/ \
    --extra-index-url https://pypi.amd.com/rocm-7.1.1/simple/
```

PyTorch on ROCm keeps the `device="cuda"` string; no code changes are needed to target AMD GPUs.

## Verify installation

```python
>>> import flashinfer_bench as flb
>>> flb.__version__
'0.0.1'
```
