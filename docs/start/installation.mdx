## Prerequisites

- OS: Linux
- Python: 3.10, 3.11, 3.12, 3.13

## Python Package (WIP)

FlashInfer-Bench is available via pip:

```bash
python3 -m pip install flashinfer-bench
```

## Install from Source

You may want to install FlashInfer-Bench from source code for development purposes.

```bash
# Clone the FlashInfer-Bench repository
git clone https://github.com/flashinfer-ai/flashinfer-bench.git

# Install the Python package
pip install -v -e .
```

## AMD ROCm / CDNA GPUs

On AMD Instinct GPUs (CDNA3 gfx942 — MI300X/MI325X; CDNA4 gfx950 additive), the GPU dependencies
come from AMD's package indexes rather than PyPI.

> ROCm support (the `docker/rocm/` container and the `[rocm]` extra) lives in the ROCm fork/branch,
> `AMD-Ecosystem/flashinfer-bench` — clone that (not the upstream URL above) to get these scripts.

The supported, reproducible path is the ROCm dev container:

```bash
# Build and enter the ROCm dev image (ROCm 7.2 + torch-ROCm + amd-flashinfer + amd_aiter + tvm-ffi)
bash docker/rocm/run.sh
# Validate the stack end-to-end on the GPU
bash docker/rocm/run.sh python docker/rocm/validate_p0.py
```

See `docker/rocm/README.md` for details. To install into an existing ROCm environment instead:

```bash
# 1) ROCm build of torch (match your ROCm version). The Radeon URL is a find-links page
#    (not a PEP 503 index), so use -f to keep PyPI available for torch's pure-python deps.
pip install torch -f https://repo.radeon.com/rocm/manylinux/rocm-rel-7.2/
# 2) flashinfer-bench + ROCm extras. The two AMD wheels are published under different, ROCm-version-
#    specific index paths (mirrors docker/rocm/Dockerfile) — don't mix versions:
#      amd-flashinfer (imports as `flashinfer`) -> rocm-7.2.0 index
#      amd_aiter (AITER-backed solutions)       -> rocm-7.1.1 index
pip install "flashinfer-bench[rocm]" \
    --extra-index-url https://pypi.amd.com/rocm-7.2.0/simple/ \
    --extra-index-url https://pypi.amd.com/rocm-7.1.1/simple/
```

PyTorch on ROCm keeps the `device="cuda"` string; no code changes are needed to target AMD GPUs.

## Verify installation

```python
>>> import flashinfer_bench as flb
>>> flb.__version__

```
